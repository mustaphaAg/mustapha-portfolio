# Mustapha Abdullahi Garba — AI Portfolio

A simple, responsive portfolio website built with HTML, CSS, and JavaScript.

## Publish with GitHub Pages
1. Sign in to GitHub as `mustaphaAg`.
2. Create a **Public** repository named `mustapha-portfolio`.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. After GitHub Pages finishes publishing, visit:
   `https://mustaphaAg.github.io/mustapha-portfolio/`
